# Sql Server module

## Summary

The `sql_server` module provides a comprehensive Terraform solution for setting up SQL database.
This module streamlines the process of creating and configuring SQL Servers. It handles essential tasks such as provisioning the necessary infrastructure, defining deployment configurations, and establishing platform-specific settings. By abstracting these complexities, the module ensures consistent and efficient deployment of web apps, regardless of the underlying operating system.

## Local SQL admin password

The module creates the local SQL admin with a 32-character password generated by
`random_password`. That value exists only to guarantee a strong starting password — it is
never written to Key Vault, never exposed as an output, and is not meant to be looked up.

When the account is actually needed (for example a BACPAC export/import, which the
ImportExport service can only perform with SQL authentication), reset the password
out-of-band and use it once:

```bash
az sql server update \
  --name <sql-server-name> \
  --resource-group <resource-group> \
  --admin-password '<new-password>'
```

The Azure API never returns the administrator password, so Terraform cannot detect drift on
it. An out-of-band reset will not be reverted by a later `terraform apply`, and no
`lifecycle` block is needed to protect it.

Note that with `azuread_authentication_only_enabled = true` (the default) SQL authentication
is disabled server-wide, so the local admin cannot connect until that flag is turned off.
Terraform will set it back to `true` on the next apply.

## How to use it?

A number of code snippets demonstrating different use cases for the module have been included to help you understand how to use the module in Terraform.

## SQL Servcer with public access disabled

```hcl
module "sql_server" {
  source              = "git::github.com/Nmbrs/tf-modules//azure/sql_server"
  workload            = "sqlservername"
  resource_group_name = "resourcegroupsqlserver"
  environment         = "dev"
  location            = "westeurope"
  local_sql_admin     = "sqllocaladmin"
  public_network_settings = {
    access_enabled  = false
    allowed_subnets = []
  }
}
```

## SQL Servcer with public access enabled

```hcl
module "sql_server" {
  source              = "git::github.com/Nmbrs/tf-modules//azure/sql_server"
  workload            = "sqlservername"
  resource_group_name = "resourcegroupsqlserver"
  environment         = "dev"
  location            = "westeurope"
  local_sql_admin     = "sqllocaladmin"
  public_network_settings = {
    access_enabled  = true
    allowed_subnets = [
      {
        subnet_resource_group_name = "subnet_rg"
        virtual_network_name       = "vnet_name"
        subnet_name                = "subnet_name"
      },
      {
        subnet_resource_group_name = "subnet_rg2"
        virtual_network_name       = "vnet_name2"
        subnet_name                = "subnet_name2"
      },
      {
        subnet_resource_group_name = "subnet_rg3"
        virtual_network_name       = "vnet_name3"
        subnet_name                = "subnet_name3"
      },
    ]
  }
}
```
